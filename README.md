# Pixelwild · Beta 0.1

Оригинальная одиночная 2D-песочница для Android и браузера. Добывай блоки, создавай инструменты, строй и исследуй пещеры. Android-приложение содержит игру целиком и работает без интернета. Аккаунт нужен только для переноса мира через облако.

## Скачать и запустить

1. Открой [Releases](https://github.com/Bloodexchange/pixelwild-beta/releases) и скачай APK последней беты.
2. На Android открой файл и разреши установку приложений из этого источника, если телефон попросит.
3. Нажми «Начать приключение». Интернет и регистрация для игры не нужны.
4. Для облака открой «Аккаунт», зарегистрируйся по почте и паролю, затем выбери «Сохранить в облако».

Веб-версия: https://pixelwild-beta.vercel.app

## Что есть

- Процедурный мир 256 × 96 блоков, деревья, пещеры, уголь, железо и кристаллы.
- Добыча, строительство, рюкзак, верстак и три улучшения кирки.
- Слизни, атака, здоровье, восстановление и возрождение без потери ресурсов.
- День и ночь: цикл 12 минут, время определяется часами и продолжается после выхода.
- Сенсорное управление, клавиатура, звуковые эффекты, пауза.
- Локальное автосохранение каждые 5 секунд, экспорт/импорт JSON; на Android экспорт через системное меню «Поделиться».
- Регистрация и вход через Better Auth; пользователи, сессии и миры в Neon PostgreSQL.
- Облачное сохранение с проверкой версии. Данные другого аккаунта недоступны.
- После явного выбора загрузки/сохранения — облачное автосохранение каждые 30 секунд в этой сессии. При конфликте оно останавливается, локальный мир сохраняется.

## Управление

| Действие | Компьютер | Android |
|---|---|---|
| Идти | A/D или стрелки | Стрелки слева |
| Прыгнуть | Space / W | Стрелка вверх |
| Добывать | Зажать блок мышью | Зажать блок пальцем |
| Строить | B → выбрать блок → нажать место | «Стройка» → блок → место |
| Атаковать | F | Меч |
| Крафт | E | «Крафт» |
| Пауза | Esc | «Меню» / системная кнопка назад |

Сначала создай 8 досок, затем верстак. Поставь его рядом, собери 8 камня и 3 дерева для каменной кирки. Для кристаллов нужна железная кирка.

## Ограничения беты

Это ранняя самостоятельная игра, не копия Minecraft или Terraria. Пока нет мультиплеера, жидкости, фермерства, печей, больших биомов, сложных мобов и бесконечного мира. Один активный локальный и один облачный мир на аккаунт; дополнительные миры можно сохранять в JSON. Факелы — размещаемые блоки; полноценное распространение света планируется отдельно.

Экран не засыпает во время открытой игры. Android может приостановить приложение в фоне; после возвращения пересчитывается время суток. Монстры в закрытом приложении не симулируются. Закрытие до следующего сохранения может потерять до 5 секунд прогресса. При удалении приложения локальный мир удаляется — сделай экспорт или облачное сохранение.

В бете нет подтверждения почты и восстановления пароля. Пароли хеширует Better Auth. Native-сессия хранится в Preferences внутри песочницы приложения, резервное копирование Android отключено. Для массового выпуска нужны почтовый провайдер, восстановление пароля и дополнительная проверка безопасности.

APK тестовой сборки подписан постоянным ключом беты из GitHub Secrets. Для Google Play нужен отдельный релизный процесс. Проверка на физическом телефоне остаётся обязательной: установка, клавиатура, фон/возврат и экспорт через системное меню.

## Разработка — простые шаги

Требования: Node.js 22+, Git, GitHub CLI, Vercel CLI. Для локальной сборки Android — JDK 21 и Android SDK 36; GitHub Actions уже содержит нужные инструменты.

```powershell
git clone https://github.com/Bloodexchange/pixelwild-beta.git
cd pixelwild-beta
npm ci
npm test
npm run build
npm run preview
```

Открой адрес, напечатанный последней командой. `npm run dev` запускает разработку фронтенда. API работает на Vercel; локальный API можно запускать через `vercel dev` после настройки окружения.

### Повторная настройка облака

1. `vercel login` — подтвердить вход в браузере.
2. `vercel link` — выбрать существующий `pixelwild-beta`. Не создавать ещё одну базу для уже настроенного проекта.
3. `vercel env pull .env.local --yes` — скачать окружение, не публикуя файл.
4. `npm run db:migrate` — создать недостающие таблицы.
5. `npm test` и `npm run build` — проверить проект.
6. `vercel deploy --prod --yes` — опубликовать.

Для нового независимого проекта: сначала `vercel integration add neon --billing-plan free_v3 --meta region=fra1 --meta auth=false`. Задать `DATABASE_URL`, случайный `BETTER_AUTH_SECRET` длиной не меньше 32 символов и `BETTER_AUTH_URL` с HTTPS-адресом сервера. `VITE_API_URL` — публичный адрес API для Android; это не секрет. Не помещать секреты в `VITE_*`.

### Собрать следующий APK

1. Внести изменения и выполнить `npm test` и `npm run build`.
2. Отправить коммит в `main`.
3. Открыть GitHub → Actions → Build Android Beta.
4. Дождаться зелёного статуса и скачать артефакт `pixelwild-beta-apk`.

В Repository Variables должен быть `VITE_API_URL=https://pixelwild-beta.vercel.app`. В Secrets — постоянный `ANDROID_DEBUG_KEYSTORE` в Base64. Ключ не включать в репозиторий. Для локальной сборки: `npm run android:sync`, затем `android/gradlew.bat -p android assembleDebug`.

## Проверки

Опубликованный APK прошёл офлайн-проверку в эмуляторе Android 15. Подробности, ссылки на CI и границы проверки: [отчёт](docs/VERIFICATION.md).

`npm test` проверяет генерацию, крафт, ход времени и валидацию недоверенных сохранений. `node scripts/smoke.mjs` при запущенном preview проверяет движение, добычу, крафт, сохранение после перезагрузки и сенсорное меню через установленный Chrome; скриншоты лежат в игнорируемой папке `artifacts`.

Код: TypeScript + Canvas, Vite, Capacitor 8, Vercel Functions, Better Auth, Neon PostgreSQL. Графика нарисована кодом; чужие игровые текстуры не используются. Документация: [Capacitor](https://capacitorjs.com/docs), [Better Auth](https://better-auth.com/docs), [Neon](https://neon.tech/docs), [Vercel](https://vercel.com/docs).
