# Проверка беты 0.1.0

Проверен опубликованный APK `pixelwild-beta-0.1.0.apk`, размер 4 314 108 байт.

SHA-256: `0ba5409ea117a8b7a89db6513dc4d8d53af2cff2825158d48ba6726e74efdc16`.

## Подтверждено

- TypeScript и production-сборка Vite проходят.
- Четыре теста: генерация и безопасная точка старта; расход ресурсов при крафте; ход времени вне игры; проверка недоверенных сохранений.
- Chrome: меню, крафт, движение, добыча, сохранение после перезагрузки, движение без сети, мобильные кнопки. Ошибок JavaScript не обнаружено.
- Опубликованный Vercel API + Neon: регистрация, вход, выход, запись/чтение мира, конфликт версий, отклонение повреждённого мира, отказ без авторизации, отдельные миры разных пользователей, native Bearer-сессия, отказ для недопустимого Origin.
- Android 15, эмулятор x86_64: APK установлен, Wi-Fi и мобильные данные отключены до первого запуска; игра запустилась, доски и верстак созданы, сохранение восстановлено после перезагрузки WebView, приложение вернулось из фона. Ошибок JavaScript в проверке не обнаружено.
- Публичная ссылка APK отвечает HTTP 200. Игра и ресурсы включены в APK; удалённый `server.url` не настроен.
- `npm audit --omit=dev --audit-level=high`: уязвимостей не найдено на момент проверки.

## Границы проверки

Физический телефон не использовался. Ещё нужно проверить разные модели Android, системное меню экспорта файлов, набор текста экранной клавиатурой, долгую игровую сессию и расход батареи. Проверка эмулятора не подтверждает отсутствие всех игровых ошибок.

Восстановление пароля, подтверждение почты и мультиплеер отсутствуют в этой бете.

Vercel опубликован через CLI. Автоматическое подключение GitHub → Vercel не настроено: Vercel требует привязать GitHub в Login Connections. Это не мешает текущему сайту и обновлению командой `vercel deploy --prod --yes`. Автоматическая сборка APK при изменениях игры в `main` настроена.
